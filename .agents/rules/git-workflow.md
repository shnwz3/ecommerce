# Git & Commit Rules

## Do Not Commit or Push Directly
- **NEVER** run `git commit`, `git push`, `git merge`, or `git tag` automatically or directly unless the user explicitly requests a commit or push with a specific commit message.
- All code changes should remain as local working directory edits for the user to review.
- Do not stage (`git add`) or commit changes on behalf of the user without explicit permission.
